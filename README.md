# OpenClaw Gmail

Personal-use Gmail integration for my OpenClaw AI assistant setup.

## What it does

- Reads my Gmail (labels, messages, threads) so the assistant can summarize mail, find receipts, and manage newsletters
- Drafts and sends emails on my behalf when I ask it to
- Runs on my own Mac mini

## Why

Gives my self-hosted assistant access to my inbox. Personal use only — I am the sole user.
